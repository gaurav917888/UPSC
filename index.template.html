    Question classification methodology

    Primary category and secondary tags

    Each question receives exactly one primary category. Secondary tags may record another subject, current-affairs linkage or tested skill. Main subject totals must sum to the question count for that paper. Multitag charts must be labelled separately.

    Questions that genuinely combine domains can be assigned a “mixed / interdisciplinary” primary category; the decision and confidence should be recorded.

    Difficulty and confidence

    Difficulty is an analytical estimate—not official—unless the exam authority publishes a label. Rubric: number of reasoning steps, factual specificity, ambiguity of options, interdisciplinary load, elimination demands and concept familiarity.

    Record classification confidence, answer-key status and ambiguity flags per record. Never substitute user mock accuracy for official question difficulty.

    Static versus current-affairs linked

    Apply a documented rule: classify a question as current-linked when a contemporary development materially provides the hook or changes the information needed; otherwise label it primarily static. Record cross-tags without double counting the primary distribution.

    Validation checks

    Reconcile question IDs/numbering with each source PDF; check that each question has one primary category; verify the question total against the paper; separately review answer key, withdrawn/disputed questions and option-text transcription; publish unresolved cases rather than forcing a label.

    Build limitations / unresolved work

    • The official paper index confirms paper availability for 2026–2017, but individual question text from those PDF files has not been imported into the database in this build.
    • Question-by-question answer-key matching, topic counts, 10-year distribution charts, volatility estimates, difficulty shares and current-affairs-linkage percentages are therefore not yet computed.
    • Answer-key publication status has not been individually reconciled for each year/question in this build. The official answer-key portal is linked above.
    • The 2026 age/attempt summary and cutoffs in the supplied handbook are cycle-specific; future rules can change.
    • Browser local storage does not synchronise progress across devices and may be cleared by browser settings.
